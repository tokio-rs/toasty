The standalone toasty command-line tool.

Installed with cargo install toasty-cli and run from any Cargo package that uses Toasty. Schema-bound commands build the package’s bin (or its lib as a cdylib) and run it with TOASTY_DUMP_SCHEMA set, which makes a constructor inside toasty dump the schema and exit. See docs/dev/design/standalone-cli.md.

The library exists for the binary and its tests; its API is not stable.
