Module embed_enum_variant_patch 

Source
Expand description

stmt::patch may step through embedded structs and may replace an embedded enum as a whole, but it may not enter an enum variant. These tests pin that boundary: a path into a variant rejects the whole update with unsupported_feature before any write, while the supported forms on the same model keep working.
